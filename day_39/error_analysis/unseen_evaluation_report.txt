MANUAL ERROR ANALYSIS (based on visual review of prediction images)
---------------------------------------------------------------------

The prediction images generated by YOLO were visually inspected for duplicate boxes, false positives, missed detections, severe over-detection, and low-confidence predictions.

1. DUPLICATE / OVERLAPPING BOXES ON THE SAME SHOE
The model sometimes draws multiple overlapping boxes on one shoe instead of producing one clean bounding box.
- catkin-childrens-shoe-1728294: one baby shoe receives 3 overlapping boxes.
- e_stamm-shoes-4655404: the same shoe receives 2 overlapping boxes.
- usa-reiseblogger-running-5370071: the right shoe receives 2 overlapping boxes.

2. FALSE POSITIVES ON TEXT / NON-SHOE OBJECTS
The model sometimes detects regions that are not shoes but contain similar shapes, textures, or patterns.
- e_stamm-shoes-4655404: letters in the word 'BOOST' are incorrectly detected as shoes.
- planet_fox-ball-8048205: part of a soccer ball is incorrectly detected as a shoe.

3. MISSED DETECTIONS
The model sometimes detects only one object when two or more shoes are present.
- spiralni-shoe-4814211: two hiking boots are present but only one bounding box is produced.
- ddcreativohn-shoes-3967944: two hanging shoes are present but only one is detected.

4. SEVERE OVER-DETECTION ON CLUTTERED / REPETITIVE SCENES
- ivabalk-bowling-shoes-2779989: the model produces 105 detections on one image containing many similar bowling shoes, with numerous duplicate and overlapping boxes.

5. LOW CONFIDENCE ON PARTIAL / OCCLUDED / TEXTURED SHOES
Some correct detections have relatively low confidence when shoes are partially visible, heavily textured, worn, cropped, or photographed from unusual angles.
- ddcreativohn-shoes-3967944: approximately 0.43 confidence.
- spiralni-shoe-4814211: approximately 0.46 confidence.
- un-perfekt-sports-shoes-3994967: approximately 0.43 average confidence.

WHERE THE MODEL PERFORMS WELL
------------------------------
The model performs better on clearly visible shoes with simple backgrounds such as grass, pavement, studio backgrounds, and clear individual boot images.
- homar-converse-1935026: 0.8542 average confidence.
- rojesh55-sport-7047874: 0.8212 average confidence.
- active-boots image: strong individual boot detections.
- wal_172619-pedestrian: several shoes detected across different people.

CONCLUSION
----------
The unseen-image testing shows that the model can detect shoes in different real-world scenes, but visual inspection reveals duplicate detections, false positives, missed objects, over-detection in cluttered scenes, and lower confidence for unusual viewpoints. Since the unseen images have no ground-truth annotations, this batch should be considered a qualitative/manual evaluation rather than a formal Precision, Recall, or mAP evaluation.
